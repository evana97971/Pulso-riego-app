🌾 Pulso de Riego

Sistema Inteligente de Monitoreo y Gestión de Riego

Revoluciona tu Sistema de Riego

Monitorea en tiempo real el drenaje de tus lotes y optimiza tu consumo de agua con inteligencia artificial

Características Principales

👤

Autenticación Segura

Sistema de login con múltiples roles de usuario: Administrador, Ingeniero y Operador

📊

Monitoreo en Tiempo Real

Visualiza el estado de drenaje de cada lote y recibe análisis automático

💧

Pulsos de Riego

Registra y analiza cada pulso de riego para optimizar tu consumo de agua

📱

Interfaz Moderna

Diseño intuitivo con Material Design 3 para la mejor experiencia de usuario

💾

Base de Datos Local

Almacenamiento local con Room Database para acceso sin conexión

🎯

Recomendaciones Inteligentes

Recibe sugerencias automáticas basadas en el análisis de drenaje

📲 Instalación

Para ejecutar la aplicación en tu dispositivo Android:

# Clonar el repositorio git clone https://github.com/evana97971/Pulso-riego-app.git cd Pulso-riego-app # Compilar ./gradlew build # Ejecutar ./gradlew installDebug

Requisitos: Android 24+, Android Studio 2023+
